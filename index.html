Local AI usage dashboard

See which agents and models use your tokens, how caching changes the picture, and where collection is incomplete. Your records stay on your computer.

Screenshots use English application labels and follow this site’s theme. See screenshot privacy for capture details.

Token and quota statistics

Input, output and cache usage are kept separate. Missing values remain unknown, and subscription quotas are shown independently of tokens.

Local storage

Read local agent files and explicitly enabled local telemetry. No account login, cloud database or remote usage report is required.

Collection status

Collection status explains versions, incomplete fields and parsing failures. A supported parser does not imply that every client records every request.

Development references

Developers can inspect the data model, adapter sources, migrations and native acceptance records alongside the implementation.

Usage trends

Select a time range, agent and model to compare recorded calls, token usage and cache-read share. Charts support interval selections; totals and model rows follow the selected interval. See the dashboard guide.

Record details

Inspect the time, agent, model, input, cache-read and output fields of individual normalized records. Filter the table by time range, agent and model. Prompts, responses and tool output are excluded. Read record fields.

Source management

Enable local sources, assign their user and choose their collection schedule. Source status and the last successful collection help identify which files need attention. See source management and client support for verified formats.

Language and appearance

Choose English or Simplified Chinese, a light or dark theme, and the statistical timezone. Manual source directories can restrict collection to the files you select. See language and accessibility and collection settings.
