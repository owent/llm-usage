                本轮实现与范围调整（2026-10-07）

                版本 0.2.1，cwd 为仓库根；PowerShell 7、Node 24.21.0、Rust 1.98， WSL Debian / rootless Podman 5.4.2。未提交、推送或发布，历史 CI 不能确认本轮代码通过检查。 用户授权指定 Provider 真实请求、Zed 配置、明细 Merge、用量与费用提醒及 F1 核查； 要求环境无法验证的项移出计划。移出项没有标记为通过。

                实现与真实来源

                新增 明细交换 与 用量与费用提醒，事务、原生 IPC 和十语言已实现。 明细保留完整标准化事件、质量、来源修订/冲突、累计和归档；默认禁用导入来源， 仍须遵守保留下限、完整来源日、保留归档分区与跨主机冲突规则。开启费用时同事务重算受影响日。 提醒使用本机用户、独立时区、日/月及 token/单币种发生时估算，默认关闭、精确微单位， 未知覆盖提示与提醒持久保存已提醒状态，避免重复提醒；不是账单、跨币种合计或 Agent 阻断。

                指定 Provider 凭据由 yq 在目标进程中提取，没有输出或写入普通配置/日志。 地址为 open.bigmodel.cn 的 /api/coding/paas/v4，属于 Coding Plan，不能据此确认按量实付。 Windows 直接探测两模型均 HTTP 200，各 22 输入/3 输出/25 总 token； 独立 Podman 的同端点探测 HTTP 200，16 输入/3 输出/19 总 token。 这是连接与 usage 验证，不能单独确认 Agent 接入。

                Zed 1.22.0，revision 76659a55a8c10ed355a070f8764a0b1733e3c115， 原 settings.json 增添无密钥 llm-usage-zhipu Provider，保留其他 JSONC 配置。 任务使用隔离 user-data/project、常量 OK 请求及禁用工具能力。

                原生线程 turn 数 非缓存输入 缓存读取 输出
                glm-5.3-flash 2 10,874 10,816 58
                glm-5.3 1 10,822 未报告 3

                threads.db 实际为 zstd / DbThread 0.3.0。固定修订的 ChatCompletionUsage mapper 从 prompt_tokens 减去 cache read/write，线程累计记录请求正增量，request 字段按用户 turn 保存末次请求。累计不展开为逐次事件，不按线程末次模型分配全部历史。 固定修订依据：usage mapper、 API key、 Windows 凭据。 总计非缓存输入 21,696、缓存读取 10,816、输出 61，缓存写及完整总量未知。 适配器只扩大到本次已核验 Provider/记录格式；ACP、其他 Provider、hosted 分列。

                密钥已按固定源码的目标名、Bearer 用户名、UTF-8 blob 与持久类型写入 Windows 凭据库，完整回读相符；另起没有运行时 key 环境变量的自有 Zed 进程，真实请求 glm-5.3-flash 成功，原生累计 10,819 非缓存输入/48 输出。此线程独立于上表三 turn， 不混入其回读期望。保留用户 Provider 配置及系统凭据，关闭全部自有测试进程。 原 JSONC 既有键保持一致；公开变更及普通 Zed 配置均未命中实际密钥。

                成品全注册表回读首次发现两个空 MiMo/DSH 实例，物理文件仍只有 Zed 一个归属。 修复仅按完整 threads.db 表/列结构确定手工文件的所属适配器，不按后缀隐藏坏文件；旧实例 恢复通过各适配器真实 discover 路径，包含 MiMo 父目录提升，只隐藏没有历史的 错误注册，保留其他错误及诊断。十项来源路由回归通过。

                首次 Zed capabilities 缺字段被拒绝，补齐后通过；共享旧进程不继承新 key， 改用自有隔离进程；GUI 不支持 CLI 的 –new；中文输入法影响自动命令输入， 修正后取得上述样本。这些失败不计为来源通过。

                既有源其他版本/协议、历史归档文件、迁移、辅助/失败/取消及更多循环 没有对应非空记录、发行物或可靠归属依据；既有样本只确认受测范围，移出本轮扩展，矩阵限制保留
                新 exporter / CLI / JetBrains OTel / trace SQLite 未有对应账户/安装或逐次用量记录；本机 VS Code 候选仅 session-store.db，不作为 trace DB。移出当前扩展，不用合成接收器确认真实 exporter 的输出格式
                旧 Windows 撤销异常原因 首次失败缺少重建旧时序所需的日志与状态；修正及 200 轮并行通过保留，不能反推旧原因。移出无法复原的调查，原因仍未证实

                更多 DPI、完整读屏、宿主登录/注销、OS 唤醒、最小 WebView 诊断 前四项用户取消；最小页面缺独立设施，资源限制已有结果，移出活动验收
                主分支、签名/公证与 Release 用户说明已完成，移出待办；本轮未重新发布/核验外部 Release，历史记录的当时结果不改写
