当前维护验证

核对日期：2026-11-16。维护验收源码版本为 0.3.9，发布准备版本为 0.3.10。 环境为 Windows x64、Node 26.13.0、 npm 12.0.2、pnpm 12.21.0 和 Rust 1.99.1。命令从仓库根目录运行；临时脚本、日志、 公开目录原始数据及隔离数据库位于 build/maintenance-20261116/。 用户随后授权提升版本、提交、附 changelog 的 annotated v0.3.10 tag、推送及发布工作流。 全部 manifest/lock 版本已同步；现有工作流在平台检查后生成草稿。下文的本地可执行程序及完整 维护检查发生在仅改版本号之前，tag CI 单独验证 0.3.10。发布准备产物位于 build/release-0310/。

计划核对

核心存储、采集、桌面查询/设置/调度、费用、交换、更新、多语言及文档均已有实现和限定范围的检查。 用户确认文档部署完成。Plan.md 现仅保留当前工作及未满足条件， 执行要求 汇总已交付范围。独立 Qoder IDE/JetBrains token 读取器及其他 F1 候选仍未实现或未核验。真实公开版本/安装器及其他平台 GUI 更新验收 与代码完成分别记录。

依赖

直接依赖版本与 npm、crates.io 注册表逐项核对。npm 和 Cargo 更新同时刷新兼容范围内的 间接依赖，两个 npm 锁文件与 pnpm 工作区锁文件保持同步。新增版本包括 Starlight 0.43.1、 Astro 7.4.12、markdownlint-cli2 0.24.1、Playwright 1.65.1、svelte-check 4.7.8、 Vite 8.3.8、rusqlite 0.43.0、Jiff 1.0.0、rfd 0.18.0、notify-rust 4.19.0、 flate2 1.1.11、toml_edit 0.25.19、ureq 3.5.2 和 zstd 0.14.4，其他直接依赖已是当前版本。 TypeScript 保留 6.0.3：@astrojs/check 和 svelte-check 都只接受 TypeScript 5 或 6， 不接受注册表最新的 7.0.2。未关闭 peer 检查。rfd 将应用 MSRV 提高至 1.92，核心保留 1.90； 固定工具链与 CI 仍为 1.99.1。Jiff 调用改用官方重命名后的 ZonedDateTime/to_zoned_datetime API，日历/DST/调度仍需通过回归。

根 npm audit 无告警。桌面 npm 报告当前 Svelte Vite 插件通过 deepmerge 引入的两条 低风险告警，注册表元数据尚无兼容修复。保留上游公告 作为依赖限制，不用 overrides 或 peer 例外隐藏告警。

离线模型

内置目录收录八个独立模型，包含 qwen4-max-preview 和文档确认的 qwen4.0-max-preview 别名。Preview 不填入价格，独立于 qwen4-max。 官方 Token Plan 说明 及产品更新不能将 Credits 转换为货币。Qoder 的 qmodel_latest 仍是未解析的路由标识。

新快照包含七个模型的九条价格：GPT-6.1 Terra 短/长上下文、Claude Fable 5.2、Gemini 4 Carbon 当前/十二月价格、Gemini 4 Hydrogen，以及原始 CNY 计价的 Qwen4-Max、 Qwen3.8-Max/Flash。依据为官方 OpenAI、 Terra 上下文价格、 Anthropic、 Google 和 Qwen 价格页。不支持或未知的缓存 TTL 不计价。保留旧快照及历史估算，独立回归覆盖新/旧数据库导入、 当前参考、未来价格区间及无价 Preview 拒绝计价。
