离线价格

desktop/src-tauri/crates/core/prices/seed-2026-10-24.json 新增 25 行官方标准 参考价格，五个快照现共 51 行。种子记录 OpenAI、Anthropic、Gemini、Kimi、 bigmodel 和 z.ai 的官方价格页 URL 及 2026-10-24 核验日期。27 项价格回归测试通过。

OpenAI 的 30 分钟／12 小时缓存写入 TTL 不符合现有 5 分钟／1 小时字段。 八条新 OpenAI 行的两种写入价格均为 NULL，该分量不计价；注释不作为可执行费率。 GLM-5.1 的输出价在文件中为 240000/280000，单位是每百万 token 0.0001 CNY， 即每百万 token ¥24/¥28，并非 ¥2.40/¥2.80。未虚构 Kimi K2.8 的精确价格， 保留已授权的 K2.7 Code 替代规则。估算仍需显式启用，保留原币种、渠道、日期和未知分量。

代码修复与回归

  • Codex 继承归属与冲突。 完整旧摘要和按继承快照归一的原生完整摘要区分 继承记录与原生响应，即使二者都没有源修订。矛盾或无法匹配的原生候选不得 在重放时跳过，也不能清除真实冲突。候选不完整的历史冲突保留 legacy_unknown。 Codex 解析器引用在重放时只能保持或升级，不能回退。测试覆盖多份继承快照、 矛盾原生响应、候选顺序、回滚及使用当前解析器的归属修正。
  • OpenCode v2 分页与异常 ID。 保留非空 ID 的原始类型，不由 SQLite 隐式转换为 文本；NULL ID 产生诊断，但不阻塞其他有效行。保存的整轮完成状态跨有界页面保留 非有限 ID 的排除状态，包括首页仅有这种 ID 的部分页。max_lines=1 的回归能继续 读取后续两条有效记录，不再反复重启首页。缺少新状态的旧上下文保持原有首轮行为。
  • Qoder 探测。 指纹探测在写锁外执行，保留 4,096 项 LRU。每个路径的探针代次 仅在探针执行期间存在。其它文件的工作不会导致重复探针或覆盖结果；同文件较新的 不稳定探针会阻止旧稳定结果写入缓存。取消和未完成行尾不会成为负缓存依据。 10 项探测测试和 16 项转录集成测试覆盖并发、替换、部分写入、注册表路由和历史。
  • Kimi wire 状态记录。 已核验的 Kimi Code 2.3.1 协议 1.5 清单仅在该产品读取器中 忽略持久化/控制状态。goal.update.tokensUsed 及其它累计字段不产生调用。 其它协议版本和 Kimi Work 1.4 保留未知类型诊断及各自版本依据。测试覆盖新增的 21 种状态类型及其跨产品边界。
  • Copilot CLI 验证程序。 空来源表让 SUM(...) 保持 None，不再抛出 InvalidColumnType。结果明确为 CHECK，不视为真实格式验收通过，也不虚构零。 Option 合计保留未知用量。
  • rusqlite 0.41 迁移。 本地源处理器按新 progress_handler 签名使用可变连接。 共享存储保留现有接口，使用作用域内 InterruptHandle 工作线程。取消期间持续中断， 让执行线程的检查可见取消状态，并在连接复用前唤醒和等待线程退出。Drop 恢复外层 控制状态，并保留暂停分类。测试强制在后续长语句开始前取消，并覆盖新的允许缓存项。
  • 测试工具与兼容检查。 portable 测试处理 Windows D: 盘根目录；原生检查恢复 所选语言，并在 Details 两页中查找记录。Rust 1.90 的 lint 修改保持原 Option 条件， 备份测试使用新的可变处理器签名。下文的完整标准验证取代中间失败结果。

失败记录与范围限制

首个单行 OpenCode 非有限 ID 用例会重复同一页；保存的整轮完成状态已修复。 新增的 Codex 用例起初会清除真实冲突并回退解析器；完整摘要比较和单调重放现在 同时保留冲突与当前版本。rusqlite 升级最初要求可变处理器，随后暴露 19 个由 MSRV 启用的 Option 简化及四个示例/测试问题。这些均已修正，未降低 lint 级别， 也未回退依赖。

首次原生暂停检查改变了 last_finished_ms。独立源码审查随后发现单次中断可能在 SQL 语句之间失效、缓存 true 导致误分类，以及嵌套作用域遮蔽。最终实现先发布取消 再中断，作用域内持续重试，恢复控制前停止并等待线程，且保留每个外层作用域的标志。 第三轮审查确认这些顺序；最终 27 项原生验收通过。一次 NSIS 尝试与原生 GUI 并发， 被进程预检拒绝；随后串行执行通过 12 项生命周期检查。

并非全部 41 个适配器都已完成真实数据验收。本轮有九个非空来源、两个空记录和 30 个无本机候选项。Qoder 没有原生客户端检查。未新增 Linux/macOS 桌面、安装或 凭据存储验收，也没有可更新的公开版本。这些属于未验证范围，不代表失败或支持。 离线价格是参考信息，不能证明实际计费渠道或账单。
