截图使用中文界面，主题跟随本站设置。采集细节见截图隐私说明。

Token 与额度统计

输入、输出和缓存用量分别记录。缺失值保持未知，订阅额度与 token 分开展示。

隐私保护

用量记录保存在您的电脑上。采集读取 Agent 文件及显式开启的遥测，看板不包含提示词与回答。

采集状态

采集状态说明版本、字段缺口和解析失败。已有解析器不代表每个客户端都记录了每次请求。

便携包

选择适合 Windows、Linux 或 macOS 的 x64、arm64 软件包，解压后打开应用。 系统要求见安装指南。

用量趋势

选择时间范围、Agent 和模型，比较已记录的调用、token 用量及缓存读取占比。 图表支持时段选区，汇总与模型行随选区更新。使用方法见看板指南。

记录详情

查看单条标准化记录的时间、Agent、模型、输入、缓存读取和输出字段，按时间范围、 Agent 和模型筛选表格。记录不包含提示词、回答或工具输出。 字段说明见记录详情。

数据源管理

启用数据源、指定所属用户并选择采集计划。来源状态及最近成功采集时间帮助定位 需要检查的文件。已核验格式见数据源管理及客户端支持。

语言与外观

选择英文或简体中文、浅色或深色主题及统计时区。手工来源目录可以将采集限制在 您选择的文件范围内。配置方法见语言与无障碍 及采集设置。
