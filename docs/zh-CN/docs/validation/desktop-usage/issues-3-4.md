# Qoder 探测与设置查询失效修复

2026-10-23，版本 0.3.4，基于 `d9c776a6c0706618e044b0f03d1532e641ce8605`。
[Issue 3](https://github.com/owent/llm-usage/issues/3) 和
[issue 4](https://github.com/owent/llm-usage/issues/4) 的根因均成立。

## 发现与修改

Issue 3 的 Qoder 标记扫描发生在未变化文件快路径之前，并位于写锁回调内。
手工路由和解析窗口还会重复执行。深度路由探测现移至存储回调之前，轻量元数据处理
保留先判定归属的原有顺序；文件准备在需要格式检测时
暂缓，释放写锁后再检测。归属变更仍在写锁内核对当前数据库。缓存最多保留 4,096 个
路径，匹配长度、修改/创建时间和首尾采样指纹；探测后再次核对指纹，避免缓存不稳定
结果。路由与解析窗口共用已完成的肯定和否定结果；取消、超时和 I/O 错误不形成缓存中的
否定依据。淘汰或重启可能再次执行有界探测。保留现有历史、诊断和旧归属恢复规则。

Issue 4 已复现无关设置自动保存后的额外汇总查询。保存现仅更新实际变化的响应式字段，
保留未变化的嵌套对象。仅时区、每周起始日或语言变更时递增统计刷新键。
别名、手工目录、主题及更新设置变更保留趋势/今日选区；语言变更仍刷新统计并清除两类
选区。定价失效与费用重算仍独立处理。

## 回归证据

Windows 11 x64、Node 24.22.0、Rust 1.99.0，使用锁定依赖。临时脚本、合成来源、
独立数据库和日志位于 `build/issues-3-4/`。

| 检查 | 结果与范围 |
| --- | --- |
| Qoder 探针单元回归 | 三项通过：未变化文件的否定探测仅执行一次；同大小/同 mtime 的尾部替换及截断使结果失效；取消不缓存否定结果；手工路由与有界解析窗口共用写锁外的一次深度探测 |
| Qoder 转录及来源路由集成测试 | 26 项通过，包括完整注册表发现、初始长消息、坏记录/不完整记录、旧检查点、历史保护下的归属、诊断及回滚 |
| 集中浏览器回归 | 模拟 IPC 通过：别名/手工目录/更新/主题变更不发统计或费用查询，保留趋势/今日选区；语言变更仍刷新并清除选区 |
| 缓存变异 | 禁用缓存命中后，未变化文件回归因重复深度探测而失败 |
| 写锁变异 | 将手工来源证据探测移入存储回调后，写锁断言失败 |
| 设置变异 | 恢复已提交的 App 组件后，别名保存的查询计数断言失败 |
| `npm run verify` | 退出 0：Rust 1,103 项通过、九项忽略，前端 32 项、脚本 20 项通过；Markdown、资源、类型、fmt、Clippy 和前端构建通过 |
| `npm run test:browser` | 退出 0：完整浏览器套件包含新增的设置查询失效/选区检查，以及既有看板、更新、遥测、语言和布局检查 |
| `npm run check:docs` | 退出 0：208 对仓库文档、21 对指南、源码注释审阅及 Astro 检查通过 |
| `npm run test:docs`、`npm run build:docs` | 退出 0：39 项测试，2,935 个发布文件的链接、搜索、语言根和更新元数据检查通过 |

每项变异均在完成后精确恢复修复后的源码。测试统计实际探测次数和 IPC 调用数，
不以依赖机器性能的耗时阈值判定。首次沙箱路由运行遇到 Windows 重命名权限；
正常进程环境使用独立临时目录重跑通过。新增记录使菜单目录从 227 项增至 228 项，
测试现要求新增路由和精确计数。中途重叠的校验在测试启动前遇到 Windows 可执行文件
共享错误 32，该次运行不计为成功验证。本任务未安装或请求原生 Qoder 客户端；这些结果
不能认证真实客户端 token 格式、实际大历史耗时、Linux/macOS 运行性能或打包 GUI
生命周期。未发送 issue 评论，也未创建提交、推送或发行。
