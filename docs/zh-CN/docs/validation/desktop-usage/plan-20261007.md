## 实现与真实来源

新增 [明细交换](../../design/desktop-usage/detail-merge.md) 与
[用量与费用提醒](../../design/desktop-usage/budget-reminders.md)，事务、原生 IPC 和十语言已实现。
明细保留完整标准化事件、质量、来源修订/冲突、累计和归档；默认禁用导入来源，
仍须遵守保留下限、完整来源日、保留归档分区与跨主机冲突规则。开启费用时同事务重算受影响日。
提醒使用本机用户、独立时区、日/月及 token/单币种发生时估算，默认关闭、精确微单位，
未知覆盖提示与提醒持久保存已提醒状态，避免重复提醒；不是账单、跨币种合计或 Agent 阻断。

指定 Provider 凭据由 yq 在目标进程中提取，没有输出或写入普通配置/日志。
地址为 open.bigmodel.cn 的 `/api/coding/paas/v4`，属于 Coding Plan，不能据此确认按量实付。
Windows 直接探测两模型均 HTTP 200，各 22 输入/3 输出/25 总 token；
独立 Podman 的同端点探测 HTTP 200，16 输入/3 输出/19 总 token。
这是连接与 usage 验证，不能单独确认 Agent 接入。

原 settings.json 增添无密钥 llm-usage-zhipu Provider，保留其他 JSONC 配置。
任务使用隔离 user-data/project、常量 OK 请求及禁用工具能力。

凭据库，完整回读相符；另起没有运行时 key 环境变量的自有 Zed 进程，真实请求

不混入其回读期望。保留用户 Provider 配置及系统凭据，关闭全部自有测试进程。

错误注册，保留其他错误及诊断。十项来源路由回归通过。

首次 Zed capabilities 缺字段被拒绝，补齐后通过；共享旧进程不继承新 key，
