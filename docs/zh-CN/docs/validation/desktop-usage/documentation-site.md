## 主题设计与对比度

实际 1920 像素首页与指南截图显示，原亮色页头、侧栏和阅读背景几乎相同；暗色主题
各区主要使用同一组绿色。这是视觉分区不明显，并未据此认定原文字对比度不合格。
2026-10-08 查阅 W3C 文字、非文字及 CSS 装饰说明，以及 Material 官方颜色用途文档；
链接与要求见文档站设计说明。

初始主题源码 6025b075 区分灰蓝页面及菜单、不透明的近白阅读区、深蓝导航及首页主区域，以及

48px，首页插图区为 40px；圆弧保持静态，不会拦截鼠标。正文、表格、卡片和图注保持
纯色背景。打印和强制颜色模式移除装饰，打印卡片标题保持黑色。已目视审阅中英文
首页、指南的亮暗主题截图，以及功能卡片和 390 像素手机页面；图片位于
build/documentation-site/theme/reviewed-source/。原有 20 张应用 PNG 保持原样。

视觉复查发现统计与隐私图标为空。已安装 Starlight 0.42.5 的 Icons.js 没有原先的
chart/shield-check 名称，analytics/padlock 则包含实际 SVG 路径。两种语言首页现使用
这些有效名称，浏览器检查拒绝空功能图标。

浏览器测试测量首页、看板指南和文档维护开发页的实际文字，包括导航、链接、表格、
图注和代码。按计算后的文字颜色及祖先背景合成颜色计算，使用未经舍入的结果与
适用的 4.5:1 或 3:1 文字要求比较；另查悬停按钮和 3px 键盘轮廓。故意将说明文字
设为不可读，确认检查会拒绝失败项。两种语言的最低实测文字对比度均为亮色
5.34665:1、暗色 5.54803:1；键盘轮廓最低为 5.16081:1。这些检查针对抽样文档页，
不代表完整 WCAG 审查，也不包括截图中的应用界面。

首次对比度运行失败，是测量代码把 alpha 分量加入三通道亮度求和，导致焦点比值无效。

还曾等待 Markdown 指南中不存在的 MDX 图形；仅在首页等待该图后恢复。
