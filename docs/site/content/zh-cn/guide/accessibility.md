## 语言与时区

应用包含简体中文、繁体中文、英文、日文、韩文、西班牙文、法文、德文、巴西葡萄牙文和俄文。
在设置中保存语言后，文案、可访问名称和区域格式立即更新。时区及每周起始日独立设置。
导出的 ISO 日期、精确数值和稳定列名不改写为依赖区域的格式。

文档提供英文和简体中文。根路径默认英文，首次按浏览器语言选择，手动选择持久保存。
深链接保留指定语言；可通过语言菜单切换对应页面。

## 主题与键盘

应用和文档均支持跟随系统、浅色和深色。保存的明确主题优先于系统配色。
未知值和状态提示同时使用文字，不仅依靠颜色。

[![中文设置示例](/screenshots/zh-CN/settings-light.png)](/screenshots/zh-CN/settings-light.png)

*真实中文设置界面，使用隔离合成数据与匿名 Demo 路径。英文文档使用对应的英文截图。*

使用 Tab 到达控件，以 Enter/Space 操作适用按钮。图表提供表格和键盘选区，方向键、Shift、
Home、End、Enter 遵循文档中的选区行为。文档提供跳转到正文、本地搜索和页面目录。
窄屏通过菜单打开导航，不依赖始终显示的侧栏。

## 核验边界

浏览器缩放、OS DPI、DOM 可访问名称、真实读屏焦点和实际语音是独立检查。
记录中的 Linux Orca 验收覆盖隔离环境下十语言五页原生导航，不能据此确认发音、硬件可听性、
每个控件或 Windows 读屏。参阅 [Orca 记录](/zh-cn/reference/evidence/orca-multilang/)和
[多语言要求](/zh-cn/reference/design/i18n/)。
