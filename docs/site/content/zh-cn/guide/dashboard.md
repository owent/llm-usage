## 五个页面

| 页面 | 用途 |
| --- | --- |
| 总览 | 今日汇总、小时活动、模型/Agent 占比及独立的历史范围。 |
| 趋势 | 按日、周、月或小时比较调用、会话和 token，查看模型行与活动日历。 |
| 数据源 | 检查发现、启用、版本、健康、用户归属及采集计划。 |
| 详情 | 分页查看标准化记录，不显示提示词、回答或工具输出。 |
| 设置 | 配置时区、语言、主题、采集、保留、交换、估算和可选遥测。 |

比较前选择用户和时间范围。总览的今日与历史区块有独立选区。点击或横向拖选图表，
可将汇总、占比和模型表限定到该时段；恢复操作清除选区。活动热力图和周分布显示完整
查询范围，不随临时图表选区缩小。

## token、调用和观测

来源字段含义已经核验时，输入分为互斥的未缓存、缓存读取和缓存创建三桶，总输入包含这三项。
供应商按输出子集报告推理时，推理包含在输出中；不能再次加到已经包含推理的输出上。

有些记录是用量观测或累计快照，而不是逐次请求。消息、工具轮、premium 请求或直方图
样本都不自动等于模型调用。哪些量可以计数取决于适配器依据。

未知表示来源没有提供经过核验的值，不等于零。其他字段缺失时，已知总量可能只是下界。
请结合覆盖提示、已知记录数和数值阅读；来源健康正常也可能存在字段缺口。

## 缓存率与模型

缓存命中率是同一有效记录集合中已知缓存读输入之和除以已知总输入之和，按输入量加权，
不是每日百分比的平均。没有有效输入或分母为零时显示缺口。

Agent、供应商、模型和计费渠道是独立身份。模型名不能证明实际计费供应商或订阅渠道。
因此，已知 token 的记录也可能缺少价格参考。

## 记录详情

打开详情页，查看所选用户的标准化记录。选择时间范围、Agent 和模型缩小表格范围。
每行展示时间、来源 Agent、模型、记录类别、已知 token 字段，以及来源提供的耗时和
会话标识。表格不包含提示词、回答或工具输出。一行记录也可能表示用量观测，而非
单次调用；请结合记录类别及来源字段规则阅读。

## 布局与无障碍

总览和趋势面板可隐藏或重排。使用布局控件调整，也可以恢复默认顺序。图表提供可读表格、
可访问名称及键盘选区。切换语言更新文案和格式，统计时区独立设置。精确行为见
[无障碍指南](/zh-cn/guide/accessibility/)和[看板说明](/zh-cn/reference/design/dashboard-polish/)。
