## 三种不同金额

| 金额 | 含义 |
| --- | --- |
| 来源报告金额 | 本机客户端报告的金额，其本身也可能是客户端估算；保留币种及依据。 |
| 历史估算 | 按观察时保存的价格快照计算，后续价格更新不改写历史。 |
| 当前 API 参考 | 使用当前已核验按量价进行对照，不等于订阅账单，也不证明计费渠道。 |

费用估算默认关闭。未知型号、渠道歧义、缺字段和不完整档位保留缺口，多币种不合并。
缓存读、缓存写、输入、输出和价格阈值遵循来源已经核验的语义。

缺少精确渠道价格时，可展示同一已核验型号的官方 API 参考，并明确标注。型号系列相似
不能作为依据。用户明确授权的 Kimi K2.8 Preview → K2.7 Code 参考标注为替代，不改变
模型身份或历史金额。

## 可选在线价格

价格刷新默认关闭。内置来源为 `models.dev/api.json`，请求不携带本机用量数据。
原始响应长缓存默认三天，可配置 1–365 天；下载或校验失败回退上一次成功缓存。
仅符合条件的官方按量条目入库，订阅占位不变成价格。

## 用量和费用提醒

用量和费用提醒默认关闭。选择本地日或月，以及已知 token 阈值或单币种历史估算阈值。
金额提醒需要开启估算。提醒只在应用内显示，不停止 Agent 或采集。

已知下界达到阈值时可以提醒；没有提醒不能证明完整用量未超设定阈值。界面说明用量或价格
部分覆盖。持久保存的用户/时区/周期/指标/币种/阈值身份防止重扫、重启后重复通知。

精确运算、归档范围、汇率参考、例外和质量规则见[价格规则](/zh-cn/reference/design/pricing/)、
[看板修正规则](/zh-cn/reference/design/dashboard-repair/)和
[用量和费用提醒规则](/zh-cn/reference/design/budget-reminders/)。
