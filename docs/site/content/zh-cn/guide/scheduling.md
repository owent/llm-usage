## 手动与自动采集

手动刷新采集所有启用来源。全局自动间隔默认一小时，零表示关闭。来源可以继承全局间隔，
也可以配置独立间隔、每日时刻或每周规则。计划只读取既有记录，不启动 Agent、
提示词或模型请求。

定点规则独立保存时区，修改统计时区不会悄然改变已有计划。夏令时中不存在的时刻顺延
到跳变后的首个有效时刻；重复时刻仅执行第一次。错过的到期请求合并，不回放成虚构用量。

两个来源实例可并行读取，单写者提交事件、游标和汇总。暂停、取消保留已确认进度。
中断或未访问的来源保持到期，读取窗结束不代表完整扫描。

## 关闭应用后的行为

| 状态 | 采集行为 |
| --- | --- |
| 窗口打开 | 已启用的自动计划可执行，手动刷新可用。 |
| 关闭到托盘 | 进程可按保存设置继续运行，关闭到托盘为可选项。 |
| 进程退出 | 进程内采集停止；显式启用的 Windows 后台任务可启动无界面采集。 |
| 自动间隔为零 | 自动采集关闭，残留系统触发也受约束；手动刷新仍有效。 |
| 休眠或注销 | 不能假定执行，需核验具体环境的 OS 生命周期和任务行为。 |

省电暂停默认开启。将采集时间过旧判断为解析失败前，请检查暂停原因。文件监听为可选项，
适用于符合条件的 JSON/JSONL 间隔来源，并保留定期轮询，以补读遗漏的文件变化。

## Windows 启动与后台任务

两项默认关闭。在设置中开启后，检查**期望**与**实际生效**状态。分钟任务检查保存的到期
规则，任务存在本身不能证明定义、可执行文件或最近运行正确。

应用仅管理完整归属与当前程序、数据目录及用户相符的任务/启动项，不删除名称相似的
无关任务。恢复、锁和生命周期细节见[调度规则](/zh-cn/reference/design/scheduling/)。

显式手动命令示例：

```powershell
LLMUsage.exe --scan-once --data-dir C:\UsageData
```

`--headless` 遵守保存的后台意图和到期规则；`--scan-once` 属于手动，读取所有启用来源。
两种模式均不创建 WebView 或遥测接收器。
