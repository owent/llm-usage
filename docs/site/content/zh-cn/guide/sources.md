## 发现与手工目录

在**数据源**查看发现的本机记录。发现规则按适配器实施，依据已核验的原生目录和环境设置。
目录中出现 Agent 名称本身不构成来源依据。应用管理的根按记录格式选择对应适配器，同一物理文件
不会跨适配器重复登记。

Agent 使用自定义本机目录时，可手工添加已核验记录的根目录。WSL/容器来源需显式添加并记录
实例身份，应用不会自动启动或扫描这些环境。网络共享、下载的远端报表或云同步会话，
不会因为已保存到本机就被确认为本机来源。

**仅扫描手工目录**同时约束 GUI 和保存的后台启动。单独改变 `--data-dir` 不限制来源发现。

## 启用与用户

来源可独立启停。停用停止后续采集，但保留已观察历史。手动刷新读取所有启用来源，
包括配置了独立自动计划的来源。到期、暂停和 Windows 后台任务见
[调度指南](/zh-cn/guide/scheduling/)。

来源归属于本机统计用户。重新分配归属改变用户的统计范围，不伪造或重复用量。
主机别名仅帮助辨认，不改变稳定身份。导入来源保留原始身份、默认禁用，需明确核对后
才可进行本机采集。

## 理解状态

| 状态或提示 | 含义与处理 |
| --- | --- |
| 已就绪 | 受查记录可读取，字段覆盖另行检查。 |
| 等待采集 | 尚未完成有效采集，刷新并检查原生记录。 |
| 部分数据需核对 | 检查未核验版本、坏字段、归属或冲突；仍可能有有效记录。 |
| 读取失败 | 核对真实错误、权限、路径和文件状态；其他来源继续采集。 |
| 版本未核验 | 兼容解析器可能接受了格式，但这不能据此确认该客户端版本。 |
| 输入不完整 | 已报告值仅为下界，本提示本身不让来源健康失败。 |

新安装版本须用其自身的非空记录核验。数据库内最高版本不能据此确认历史会话。重扫不重复入库，
并可在已消费且字节未变化的文件上重评解析规则；清空数据库不是通常的恢复方式。
