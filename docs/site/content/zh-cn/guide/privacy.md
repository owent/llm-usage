LLM Usage 从已核验本机 Agent 记录提取允许保留的统计字段，将标准化用量、来源、修订、
诊断事实和采集位置保存到本机 SQLite。看板和标准化导出不包含会话正文、回答、工具输出
或账户凭据。

读取本机保存的云端模型请求记录仍属于本地用量统计，不表示模型离线运行。
远端账单 API、跨设备账户报表、SSH gateway 和云同步会话不属于本机来源范围。

## 网络行为

- 统计不需要额外模型请求、账户登录或云端数据库。
- 可选价格刷新请求内置公共价目，不携带本机用量，默认关闭。
- 可选认证 OTLP/HTTP 接收仅监听 loopback，需要应用运行，默认关闭。
- 显式 IDE 遥测配置可能改变客户端的本机导出方式，请查看预览并保留已有目标。
- 文档站使用本地搜索和打包资源，没有分析追踪或远端字体请求；访问外部依据链接会打开外站。

## 凭据与分享

接收凭据保存在 OS 凭据库，配置预览和 IPC 不返回秘密。安全持久存储不可用时拒绝接入。
读取既有用量文件不要求模型供应商密钥。

导出包含稳定来源/主机身份。您自己的数据源或设置截图可能显示路径、别名，分享前请检查。
文档截图使用隔离合成来源和示例用户，图片旁保存来源记录。

[数据规则](/zh-cn/reference/design/data-contract/)和
[接收要求](/zh-cn/reference/design/receiver-auth/)规定准入字段及失败行为。
诊断可以解释记录缺失原因，而不暴露正文。
