## 分级保留

设置分别提供事件、小时、日、周、月、年统计保留范围。执行会删除数据的保留清理或
**清理全部数据**前，检查当前数量和清理预览。清理影响应用数据库，不修改 Agent 原始文件。

归档汇总与仍保留的明细按完整来源分区择一，不叠加。删除明细不允许从累计快照伪造
缺失 token 字段、模型或逐次调用。后续重扫遵守保存的保留清理下限，不悄然重建主动清理的历史。

## 两种交换格式

| 格式 | 保留内容 |
| --- | --- |
| 聚合交换 | 受支持的汇总分区及来源，不重建逐次记录。 |
| `llm-usage-details-1` | 完整标准化事件、字段质量、来源/主机身份、修订、冲突、累计快照和封存分区。 |

在设置中导出，通过系统对话框选择目标。导入自动识别格式，预览后事务执行。
明细包导入和导出均限制为 64 MiB。明细包不等于数据库备份，不包含采集游标、全部系统设置
或完整价格缓存。

重复导入跳过重复项。两条记录都有来源修订号时，比较修订号；否则比较生命周期顺序
（`partial < final < corrected`）。顺序更高的记录替换已有记录，更低的保留已有记录；
顺序相同但内容不同的，保留已有记录并记录冲突历史。
包中缺少记录没有删除语义。非法字段或身份冲突使整批回滚，不提交部分合并结果。

## 身份与隐私

保留稳定原始来源键及原始主机身份。不同主机上的相同路径不是同一来源。导入来源默认
禁用并归默认本地用户。导入远端记录不会将其变成当前设备的用量。

导出包含统计字段，不包含提示词、回答、凭据或工具输出。分享前检查元数据：稳定来源
身份仍可能辨认机器或数据源。参阅[隐私](/zh-cn/guide/privacy/)和
[明细合并规则](/zh-cn/reference/design/detail-merge/)。
