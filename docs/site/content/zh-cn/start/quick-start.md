LLM Usage 读取 Agent 已经保存的用量记录。查看统计不需要登录模型供应商账户，
也不需要额外发送模型请求。

## 安装并打开

1. 从[最新 Release](https://github.com/owent/llm-usage/releases/latest) 下载适合系统和 CPU 架构的软件包，
   按[安装指南](/zh-cn/start/installation/)解压或安装。
2. 打开 LLM Usage，在**设置**中选择语言、主题和统计时区。
3. 打开**数据源**，检查发现的 Agent、路径、版本及采集状态。
4. 使用**刷新**采集启用的来源，同时核对统计结果和覆盖提示。
5. 在**总览**查看今天，**趋势**查看更长周期，**详情**核对图表背后的标准化用量记录。

桌面程序支持十种语言，现有默认语言是简体中文。文档默认英文，并在浏览器使用中文时
选择中文版。文档语言不会改变应用设置。

## 确认首次结果

采集读取 Agent 保存在本地文件或数据库中的用量。刚安装的 Agent 或空会话可能还没有用量记录。
部分客户端记录请求但不提供 token 字段，这些值保持未知。
格式及版本限制见[客户端支持](/zh-cn/guide/clients/)。

如果没有数据，请检查所选用户、时间范围、来源开关、记录路径和来源状态。
按照[故障排查](/zh-cn/guide/troubleshooting/)检查，不要直接修改或删除应用数据库。
未知字段以缺口显示，不补成零。

## 可选设置

全局采集间隔默认一小时。将间隔设为零可关闭自动采集，手动刷新仍读取启用来源。
Windows 登录启动和后台任务、费用估算、价格下载、本地 HTTP 接收器及用量和费用提醒均需显式开启。
使用前请阅读各自的指南。
