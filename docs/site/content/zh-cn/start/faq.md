## 应用会调用模型计算统计吗？

不会。读取既有记录和可选的本地遥测，不需要额外模型请求、模型供应商登录或云数据库。

## 总量就是我的账单吗？

不是。原生用量、来源报告金额、发生时估算和当前 API 参考含义不同，订阅额度独立。
模型名不能证明计费渠道，不完整字段保留可见缺口。

## 为什么有些值为空？

来源没有提供已核验值。空/未知不等于零。有些客户端只记录下界或聚合观测，
应用不据此伪造逐次调用、缓存桶或模型归属。

## 发现已安装客户端就表示支持吗？

安装、配置、解析器实施和真实 token 验收是不同状态。请按准确产品、版本及记录格式查看矩阵。
文档级解析器可能尚无原生真实样本，空会话也不是格式验收。

## 能采集 WSL、容器或远端账户数据吗？

本地 WSL/容器需显式根和实例归属，应用不自动启动或扫描。远端账单/账户报表、
SSH gateway 和同步远端会话不属于本地来源边界。

## 退出后自动刷新还执行吗？

进程内采集随进程结束。Windows 后台采集需显式开启并核验任务定义，关闭到托盘是另一状态。
自动间隔为零阻止自动触发，手动刷新仍可用。

## 默认语言是什么？

仓库文档/注释和文档根路径默认英文。站点首次按受支持浏览器语言选择并保存手动选择。
桌面程序含十份语言目录，现有默认简体中文；其设置独立于文档。
